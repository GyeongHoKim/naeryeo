# 자체 호스팅 (MOTIS)

naeryeo의 경로 검색을 **여러분의 장비에서 직접 돌리는** 방법입니다. 상용 경로 검색 API의
계정도, 앱키도, 과금 정책도 필요 없습니다.

> **⚠️ 작성 중** — 이 문서의 절차와 수치는 실제 구축·계측으로 검증된 뒤 채워집니다.
> 현재 상태에서 그대로 따라 하지 마세요. 진행 상황은
> [spec 006](../specs/006-self-hosted-routing-provider/) 참조.

## 1. 무엇을 얻고 무엇을 감수하는가

**얻는 것**: 경로 검색이 외부 사업자의 과금 정책·무료 한도·약관 변경에 영향받지 않습니다.
호출 횟수 제한이 없고, 어떤 질의를 했는지가 외부로 나가지 않습니다.

**감수하는 것**: 엔진과 데이터의 운영 책임이 여러분에게 있습니다. 실시간 정보가 없고,
경로·소요시간이 상용 서비스와 다를 수 있습니다([6절](#6-데이터의-한계)).

## 5. naeryeo와 연결

```bash
naeryeo setup --provider=motis --motis-url=http://localhost:8080
```

또는 대화식으로:

```bash
naeryeo setup
# 1) 자체 호스팅 (MOTIS) 선택 후 주소 입력
```

설정을 저장하기 전에 naeryeo가 엔진에 연결해 **데이터가 적재되었는지 확인**합니다. 엔진이
응답하지만 시간표·지도 데이터가 없으면 저장을 거부하고 이 문서를 안내합니다.
