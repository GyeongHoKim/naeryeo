# Contract: 사용자 문서(README.md) 갱신

사용자 대면 기능 변경이므로 README를 함께 갱신한다(리뷰 후 사용자 지적으로 계획에 추가).
핵심 메시지: **지오코딩은 선택 기능이다 — 역/정류장 이름만 물어볼 거면 없어도 되고, 건물명·
주소로 물어보려면 Kakao 키를 등록해야 한다.**

## 변경 대상 섹션

### 1. 설치 > Skills 디렉터리 (현재 `README.md:19`)

- 현재: "... `naeryeo setup`으로 ODsay 키만 등록하면 됩니다."
- 변경: ODsay 키 등록이 기본이고, **건물명·주소 검색을 원하면 추가로 `naeryeo setup
  --geocoder`로 장소 검색 키를 등록**한다는 한 문장 추가(선택임을 명시).

### 2. 시작하기 — 신규 하위 섹션 "건물명·주소로도 검색하기 (선택)"

`3. CLI로 바로 써보기` 뒤(또는 Setup 섹션 뒤)에 신규 하위 섹션을 추가한다. 담을 내용:

- **왜 필요한가**: 경로 검색 엔진(ODsay)은 역/정류장만 이름으로 인식한다. "아이디스 타워"
  같은 건물명·주소는 좌표로 해석해 줄 별도의 장소 검색 서비스가 필요하다.
- **없어도 되는 경우**: 역·정류장 이름("강남역", "수지구청")으로만 물어본다면 이 설정은
  필요 없다. 지오코더 미설정 상태에서 역/정류장 검색은 기존과 동일하게 동작한다.
- **쓰고 싶은 경우(설정 절차)**:
  1. [Kakao Developers](https://developers.kakao.com)에서 애플리케이션을 만들고 **REST API 키**를
     발급.
  2. `naeryeo setup --geocoder` 실행 → 프롬프트에 Kakao REST API 키 입력(OS 키체인에 ODsay 키와
     **별도 항목**으로 저장).
  3. 이후 `naeryeo route --from "아이디스 타워" --to "수지구청"`처럼 건물명·주소로 검색 가능.
- **미설정 시 안내**: 건물명·주소를 입력했는데 키가 없으면 "찾을 수 없음 + `setup --geocoder`
  안내" 힌트가 표시됨을 언급.
- **삭제**: `naeryeo logout --geocoder`로 장소 검색 키만 제거 가능(ODsay 키는 유지).
- 예시 출력 블록 1개 포함(건물명 출발지 → 경로 결과).

### 3. 명령어 표 (현재 `README.md:98-104`)

행 추가/보강:

| 명령어 | 설명 |
| --- | --- |
| `naeryeo setup` | ODsay(경로 검색) API 키 등록 |
| `naeryeo setup --geocoder` | 장소 검색(Kakao) API 키 등록 — 건물명·주소 검색용(선택) |
| `naeryeo logout` | 저장된 ODsay API 키 삭제 |
| `naeryeo logout --geocoder` | 저장된 장소 검색 API 키 삭제 |

(route/mcp/--version 행은 유지.)

### 4. 아키텍처 (현재 `README.md:108-113`)

디렉터리 트리에 `internal/geocode/  # 장소 검색(지오코딩) 연동 — 건물명·주소 → 좌표` 추가.

### 5. 사용 API (현재 `README.md:121-123`) — **정정 필요(모순 제거)**

- 현재 문장: "카카오·네이버 지도 API는 대중교통 경로 검색을 지원하지 않아 제외했습니다."
  → 이 기능 도입 후 Kakao를 **지오코딩 용도로** 사용하므로 그대로 두면 모순이다.
- 변경 방향: 두 역할을 명확히 구분한다.
  - **대중교통 경로 검색**: [ODsay API](https://lab.odsay.com) 사용(카카오·네이버 지도는 대중교통
    경로 검색을 제공하지 않아 이 용도로는 부적합, Google Directions는 국내 지도 반출 규제로
    사용 불가 — 기존 설명 유지).
  - **건물명·주소 → 좌표(지오코딩, 선택)**: [Kakao Local 키워드 검색](https://developers.kakao.com/docs/latest/en/local/dev-guide)
    사용. 경로 검색 자체가 아니라 이름→좌표 해석에만 쓰이며, 키 미등록 시 이 단계는 비활성.

## 비목표(문서 범위 밖)

- 다른 지오코더(Naver/Google) 설정법은 문서화하지 않는다(지원 대상 아님).
- MCP 클라이언트별 세부 설정은 기존 문서 수준 유지.
